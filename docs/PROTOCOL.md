# 配置协议速查

设备身份保留 `C5RE`、`C5CF`、`C5 Rev.E`，保证现有设备、JSON 和系统配对兼容；KeyDeck 是仓库名与控制台工程代号。配置结构与 CRC 实现以 `firmware/core/config.c` 和 `web/public/config/schema.js` 为准。

## 传输与帧

USB：Vendor HID usage page `0xFF60`、usage `0x61`、report ID `0x20`，63 字节 payload 的前 20 字节为协议帧。BLE：加密配置服务 `c5920001-7a1b-4f3b-9c28-5a72b510e001`，命令 characteristic `c5920002-7a1b-4f3b-9c28-5a72b510e001`（WRITE with response），响应 `c5920003-7a1b-4f3b-9c28-5a72b510e001`（NOTIFY），固定 20 字节。

| 字节 | 含义                           |
| ---- | ------------------------------ |
| 0    | `0xC5`                         |
| 1    | 协议版本 `1`                   |
| 2    | 操作码；响应为请求码 `OR 0x80` |
| 3    | 序号；响应原样回显             |
| 4    | payload 长度，0–12             |
| 5    | 请求为 0；响应为状态码         |
| 6–7  | 偏移，uint16 little endian     |
| 8–19 | payload，未使用位置补零        |

请求按序执行，响应必须匹配操作码、序号与偏移。网页不会以超时作为保存成功；连接代次变化会拒绝旧请求。

## 命令

| 操作码 | 名称             | 用途                                               |
| ------ | ---------------- | -------------------------------------------------- |
| 1      | INFO             | 身份、版本、1024 字节配置长度和能力位              |
| 2      | READ             | 按偏移读取 1–12 字节                               |
| 3      | BEGIN            | 开始事务，payload 为长度 uint16 + CRC32 uint32     |
| 4      | WRITE            | 顺序写入下一段，最多 12 字节                       |
| 5      | APPLY            | 长度、CRC、语义均通过后原子更新 RAM                |
| 6      | SAVE             | 持久化当前 RAM 配置，写入并验证后回复成功          |
| 7      | CANCEL           | 丢弃上传事务                                       |
| 8      | DEFAULTS         | 将默认配置应用到 RAM                               |
| 9      | STATUS           | 连接、电量、运行层、物理输入、编码器和实际连接参数 |
| 10     | HAPTIC           | 传统脉冲试听；无震动版返回不支持                   |
| 11     | RECONFIGURE      | 在 ACK 后启用已保存的 USB / BLE 参数               |
| 12–13  | DIAGNOSTICS      | 板级与 BLE 诊断                                    |
| 14     | ADVANCED HAPTIC  | RAM 效果上传、试听、停止；无震动版返回不支持       |
| 15–16  | MOTOR EXPERIMENT | 保留的实验接口，常规两种构建不启用                 |
| 17–18  | CALIBRATION      | 触觉校准状态与任务；无震动版不启用                 |

状态 0 成功、1 帧错误、2 越界、3 事务忙、4 CRC 错误、5 配置语义错误、6 I/O 失败、7 不支持。

## 1.15 能力位

INFO 的 12 字节 payload 为 `C5RE`、major、minor、配置长度 uint16、能力 uint32。

| 位      | 含义                                    |
| ------- | --------------------------------------- |
| 0–4     | USB、BLE、原生轮盘、宏、RGB             |
| 5       | 本地触觉硬件                            |
| 6 / 7   | USB LampArray / 主机触觉                |
| 8       | 可配置回报率                            |
| 9 / 10  | 五按钮鼠标 / 宏重复模式                 |
| 11 / 12 | BLE LampArray / 主机触觉                |
| 13 / 14 | 板级 / BLE 诊断                         |
| 15      | 高级触觉                                |
| 16      | 独立状态灯设置                          |
| 17 / 18 | 可选马达声音实验 / 诊断，常规构建不设置 |
| 19      | 触觉校准                                |
| 20      | 主机灯光与触觉控制状态标志              |
| 21      | RGB 配置层与 Fn 组合                    |
| 22      | 平滑原生轮盘逐边沿输入                  |
| 23      | **无震动构建（KeyDeck 新增）**          |

无震动版设置 bit23，清除 5、7、12、15、19，保留其他常规能力。配置里的触觉字段保留，网页不发送校准请求。切换这两种构建后应重新读取 INFO，不能仅依靠版本号判断硬件。

## 配置兼容

配置共 1024 字节，含三层映射、宏、旋钮、灯光与触觉扩展区。触觉扩展位于偏移 943、长度 81；校准参数位于最后 8 字节。无震动版仍校验并保存这些字段，方便版本间迁移。

BEGIN / WRITE 属于发起的物理传输通道；另一通道不能抢占修改。CANCEL、断连和事务超时释放所有权。APPLY 失败时保留原活动配置。回报率仅在保存、回读核对后发送命令 11 启用。
