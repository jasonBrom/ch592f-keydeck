# KeyDeck 界面与文档规则

控制台采用白底、浅灰分区与蓝色操作色，保持设备工具的清晰度。文档参考 [C2000MAX-UI](https://github.com/jasonBrom/C2000MAX-UI) 的结构组织，不继承其项目功能或许可证。

## 配色

| 用途             | 色值      |
| ---------------- | --------- |
| 页面背景         | `#F6F8FA` |
| 编辑区与弹层     | `#FFFFFF` |
| 正文             | `#202A35` |
| 次要文字         | `#64717E` |
| 分隔线           | `#DFE5EB` |
| 主要操作与选中态 | `#0969DA` |
| 成功             | `#1B7B43` |
| 错误             | `#BF3636` |

只使用一个主要操作色。颜色变化用于选中、连接、保存与错误状态，不用于装饰每个功能。

## 排版与布局

- 使用系统字体：Segoe UI、Microsoft YaHei、system-ui。无需外部字体请求。
- 桌面左侧展示设备和运行层，右侧编辑配置；编辑区独立滚动，底部保存区保持可见。
- 手机使用纵向布局，缩小按键预览，底部保留测试和保存入口。
- 普通控件圆角 6–9 px，设备示意图保留实体外壳和键帽的圆角与阴影。
- 常用页签直接显示，高级参数放入折叠区；控件保留键盘焦点和方向键导航。

## 状态与文案

- 清楚区分「编辑层」「设备运行层」「启动层」，浏览配置层不改变设备。
- 草稿、测试与持久化分别呈现；设备未确认或回读不一致时，不显示保存成功。
- 无震动版显示「触觉 · 未搭载」，禁用硬件相关控件，不提示虚假的播放或校准成功。
- 离线页面显示未连接与缺失读数，不填入演示电量、版本或延迟。
- 文案说明当前操作和实际结果，避免「极致」「智能赋能」等泛化描述。
