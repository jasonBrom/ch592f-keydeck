旋钮用途

用途、转动幅度与本机实测说明 ↗

Surface Dial 模式发送原生 Radial Controller 角度和按压。Windows 轮盘菜单与应用行为由系统决定；本设备没有屏上位置检测。

角度按本机 20 脉冲／圈估算。每个触觉刻度累计发送 10°；1.15 按边沿细分发送，触觉间距不变。应用可以自行定义其他阈值。

应用角度预设（高级）

这里改变发送给 Windows 的逻辑角度，保留上方的物理转动幅度。小于应用阈值时会累积多次才切一项；本地震动不等于应用已切换。

编码器精度（高级）

20 脉冲/圈的无定位旋钮可选每刻度 4 边沿，约 18°实体转动。1.15 的原生轮盘逐边沿发送细分角度；其他模式按各自规则计步。上方累计角度决定发送给 Windows 的总量。

当前连接的是无震动版固件。按键、旋钮、宏与灯光可正常配置；此版本不启用马达驱动。
