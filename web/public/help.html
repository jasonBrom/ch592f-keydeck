连接小键盘

配置保存在设备本地。点击「连接设备」会先尝试已授权 USB，再识别 Windows 已配对蓝牙和已授权浏览器蓝牙；也可从「手动选择」指定连接方式。首次 USB 或浏览器蓝牙连接需要授权。

USB · 推荐首次连接

  1. 用数据线连接正常运行的小键盘。
  2. 在桌面 Chrome / Edge 打开此页面，点击「连接设备」自动识别；首次连接可从「手动选择」选择 USB。
  3. 在浏览器设备列表中授权对应设备；控制台随后读取配置。

请使用系统 HID 驱动。ISP 烧录模式下不能用此页面改键。

蓝牙

在手动选择中选择蓝牙，使用 Web Bluetooth 授权设备。若搜不到设备，正常开机时长按 BOOT 约 2 秒进入配对，再搜索；不要按 RESET。设备只支持一个 BLE 外围连接。

Windows 已配对蓝牙

Windows 系统配对不会自动授予网站设备权限。已在 Windows 连接的 C5，可复用系统的蓝牙连接管理，不需要删除配对。

  1. 下载最新版工程，双击 web/StartConsole.cmd。首次启动自动安装 Python 蓝牙组件；保持服务运行。
  2. 回到在线页面，展开「手动选择」，点击「Windows 已配对 · 直接管理」。若浏览器询问访问本机网络，请允许。
  3. 连接后自动读取配置。测试和保存仍由你点击，不会在连接时写入配置。

也可直接使用同一界面的 本地控制台。如果旧服务仍在运行，请关闭后重新运行最新版启动器；只刷新网页无法更新 Python 服务。

桥接只监听 127.0.0.1:8792，只允许本地控制台和官方站点 https://jasonbrom.github.io 访问限定的配置 API，并校验独立令牌与设备会话。在线页仅在你点击自动连接或 Windows 连接入口时请求访问本机；配置数据不经过 GitHub 服务器。

充电状态

「充电中」表示设备报告充电信号有效；「未在充电」表示当前没有充电信号。该硬件没有独立的充满或电源检测信号，电量百分比也是电压估算，因此网页不会据此宣称已充满。

模型与配置层颜色

在模型区域拖动旋转、滚轮缩放，也可使用加减和复位按钮。「放大预览」临时收起编辑器，按 Esc 或「返回设置」恢复。

点击配置层前的色块修改指示灯颜色。模型即时预览编辑层的配色；实际键盘在「测试」或「保存到设备」后使用该配色。指示灯亮度仍在灯光页设置。

测试与保存

操作 结果
离线编辑 只修改当前页面草稿，可导出 JSON。
测试 分包写入设备 RAM；重启恢复已保存配置。
保存到设备 写入 Flash，设备确认后完整回读校验。

连接不会覆盖已有未保存草稿。手动重新读取配置会先询问是否覆盖草稿。无震动版固件会禁用触觉编辑，保留其他功能。

仍然连不上

检查是否通过 HTTPS 或 localhost 打开、浏览器是否提供设备接口、数据线是否支持传输、设备是否正常运行。另一页面占用连接时应先断开；更换固件的 HID 描述符后，可能需要删除旧蓝牙配对并重新配对。
