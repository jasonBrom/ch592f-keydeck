# CH592F Rev.E 板级适配

**1.13 当前行为**：滚动模式每步最多使用2个有效编码器边沿；新增独立 RGB 配置层指示与专用 Fn 切层组合。默认不启用新扩展，不重写既有配置。参见 [CONSOLE_LAYERS_1_13.txt](../docs/CONSOLE_LAYERS_1_13.txt)。

**1.12 触觉基础（1.13 延续）**：默认标准脉冲24ms，可调4–120ms，旋转独立绑定126；快速旋转合并触觉而保留输入格数。驱动开放有边界的闭环调校，实际校准结果只读，校准失败可恢复上次真实参数。采样时间改变时重算额定代码，默认仍为0x25/峰值0x42。旧文中的1.11/80ms是历史记录。装壳、桌面传递和使用步骤见 [ROTARY_HAPTICS_1_12.txt](../docs/ROTARY_HAPTICS_1_12.txt)。

`board_init()` 在 60MHz 系统时钟配置后、`c5_init()` 前调用。主循环通过 Timer3 的 60MHz 自由运行计数器累计毫秒，调用 `board_tick(ms)`；同一计数器提供板级 I/O 超时，不输出到引脚，不占用 BLE 的 Timer0/RTC。应用计时不再依赖外置 32.768kHz 晶振，即使 BLE RTC 停止，USB 输入、RGB 和回报率切换仍可继续。必须至少每 1.118 秒轮询一次 Timer3；当前同步 Flash/I²C 操作均应保持在此预算内。没有调用串口调试初始化；PA8/PA9 留给编码器。

启用 `C5_BOARD_DIAGNOSTICS` 时，配置协议 INFO 能力位 `0x2000` 表示支持只读命令 12。其 12 字节负载依次为应用 uptime 毫秒（LE32）、RTC 原始计数（LE32）、低有效原始按键位图（6 位）、编码器 AB（2 位）、触觉故障阶段、回报率切换阶段。诊断不保存配置，也不驱动 GPIO。

蓝牙使用 SDK 校准的内部低频时钟（`CLK_OSC32K=1`）。1.11 正常运行时长按 **BOOT 约 2 秒**断开当前蓝牙连接，重新广播两分钟，允许同一电脑重连或另一电脑配对；不再使用1.8的最近地址黑名单。保留配置及配对记录。PA15蓝色闪烁（250ms亮/250ms灭），配对期间忽略日常闲置超时，并保证至少50%的指示灯亮度。断开请求会重试，离线时每500ms检查并恢复广播；配对窗口内连接30秒仍无法完成加密和HID/配置订阅则断开后继续广播。已有主机可能自动抢连，换机前可先关闭旧主机蓝牙。正常关机/失联仍熄灯，处理器及BOOT检测继续运行。详见 `../docs/RELIABILITY_1_11.txt`。

INFO 能力位 `0x4000` 表示支持只读命令 13：字节 0 为 BLE 初始化/服务成功/加密连接/配对窗口/BOOT 原始按下的标志（位 0–4），字节 1 为 GAP role，字节 2 为最近启动/配对请求状态，字节 3 为 `CLK_OSC32K`，字节 4–7 为配对窗口开始毫秒（LE32），字节 8–11 为应用 uptime（LE32）。该命令用于实板检查广播、按键和时钟，不触发配对或擦写。

| 接口 | 本版实现 |
|---|---|
| 五键/旋钮按压 | PA4、PA5、PA12、PB7、PB12 / PB4；内部上拉，低有效，连续 5 个实际毫秒样本去抖 |
| 编码器 | PA8/PA9 每轮主循环采样；4 边沿模式只接收完整 Gray-code 周期，非法双边跳变后重新同步；每步边沿数读取配置 1–4，支持无定位旋钮 |
| 触觉 | PB15 SCL / PB14 SDA，开漏软 I²C；150µs 拉伸超时，9 时钟恢复，总线故障不死循环 |
| 背光 | PB13 五颗 GL6028，RGB 顺序；PA15 独立 XL4020，GRB 顺序；变化时最高 40fps |
| 电池 | PA14/AIN4、0dB ADC，零点校准，8 样本平均，1M/470k 分压；首次等待 250ms |
| 充电 | PA13 STAT 低电平报告充电；高电平不能区分充满、未插线和无电池 |
| 配置 | DataFlash `0x4000–0x4fff` / `0x5000–0x5fff` 双槽；每槽独立擦除块，CRC32，提交头最后写入，读回校验后才确认成功 |

DataFlash `0x7000–0x7fff` 整块保留给 BLE 配对。EEPROM ROM API 的缓冲必须 4 字节对齐；实现只占一个 256 字节页缓存。相同配置再次保存不擦写。不在输入/灯效循环里自动保存。保存是 ROM 同步擦写，可能短暂停顿；必须在实板检查连接下保存和断电恢复，不能仅用主机单元测试宣称 Flash 电气行为已验证。

固件 1.4 针对此设备实际安装的 **AAC 0809、170±10Hz、0.9Vrms LRA** 适配，供应商规格见 [AAC0809_SUPPLIER_SPEC.png](../docs/AAC0809_SUPPLIER_SPEC.png)。它替换了原 BOM 的 LD0832AA-0099F（235Hz、1.8Vrms），原硬件 BOM 仅记录原设计。Rated `0x25`（170Hz 时约0.882Vrms，在160–180Hz公差内均低于0.9Vrms）；Clamp `0x42`（最大峰值1.40052V，低于使用上限1.0Vrms正弦的峰值）；DriveTime `24`（Control1 `0x98`）；开环周期 `0x3c`，但开环及自动开环回退均关闭。未使用超出供应商范围的过驱电压；寄存器设定值不是示波器实测值。

上电异步校准约一秒，最多等待1.4秒；芯片实际生成的补偿/BEMF参数保留，失败后拒绝触觉命令，键盘/旋钮仍可用。1.11标准反馈改为80ms脉冲，写入零立即开始停止/刹车；ROM与RTP都使用同一套电压限制，网页增益不改变额定电压或校准结果。`board_haptic_fault()` 返回非零的总线、识别、配置、校准或播放故障阶段，0无已记录故障。更换马达参数应重新计算并校准；原配1.8Vrms马达不能把本版当作对应的驱动配置。实物清脆度与异响需要在最终固定/装壳状态验收。

电池百分比是单节锂电的近似电压曲线，不是电量计。系数来自实际分压与 WCH ADC 0dB 的 `Vin=ADC×1.05/2048`，再乘用户校准 ppm；异常电压返回未知。充电或负载下读数会偏移。ETA6002 由电阻固定约 303mA，固件无法调整充电电流。此板没有 VBUS 检测，USB 是否可用以 USB 枚举/挂起状态判断。

首次 USB ISP 烧录需核对芯片配置：`CFG_DEBUG_EN=0` 才释放 PB14/PB15，`CFG_RESET_EN=1` 保留 PB23 复位，`CFG_BOOT_EN=1` 允许 PB22 BOOT。本模块不改写 InfoFlash；RESET 保留复位功能，BOOT 在运行时用于配对，上电或复位时按住则仍进入 ROM 下载模式。硬件无线射频、晶振和 USB 电源预算仍应按板级电气评审进行首板验证。

RGB 引脚无法直接接所需的 SPI MOSI/PWM DMA，所以当前用 RAM 中固定指令输出。GL 的数据次序和 0.30/0.90µs 高电平不能套用 XL 的 GRB/WS2812 参数。两个灯串分不同 tick 发送；中断屏蔽仅覆盖该串的数据，锁存的低电平在中断恢复后自然等待。`board_rgb_max_irq_ticks()/60` 可读出最长屏蔽微秒数。**CPU 指令数不等于引脚实测时序**，首板必须用示波器确认高电平、复位间隔、满帧中断屏蔽时间与 BLE 收发稳定性；未完成前属于待验证输出路径。若精密无线延迟目标要求完全不屏蔽中断，后续 PCB 应把灯数据改到可 DMA 输出的管脚。
